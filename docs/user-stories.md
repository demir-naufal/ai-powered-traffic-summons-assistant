# User Stories

### Story 1 (FR4)
1. As a car driver, I want to ask the chatbot if my traffic summons qualifies for the active 50% discount campaign, so that I can pay the reduced amount online before the campaign deadline ends.
**Acceptance Criteria:**
    1. When a user asks about an active discount campaign, the system displays the correct discount percentage and campaign end date.
    2. When an eligible summons is checked, the system calculates and displays the final discounted payable amount.

---

### Story 2 (FR3)
2. As a vehicle owner, I want to know which of my summonses are blocking my annual road tax renewal, so that I can prioritize settling the urgent ones first.
**Acceptance Criteria:**
    1. The system explicitly flags any summons that causes a JPJ road tax renewal blacklist.
    2. The system clearly separates pay-online compoundable fines from mandatory court appearance summonses.

---

### Story 3 (FR1)
3. As a motorist who prefers using Bahasa Melayu, I want to ask questions in everyday conversational language, so that I do not have to travel and wait in long queues at a police station counter just to get basic help.
**Acceptance Criteria:**
    1. When a user sends a query in Bahasa Melayu, the system responds accurately in clear Bahasa Melayu.
    2. Every response includes official PDRM source references to verify the answer's credibility.
