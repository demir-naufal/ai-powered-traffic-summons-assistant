# User Stories

1. As a car driver, I want to ask the chatbot if my traffic summons qualifies for the active 50% discount campaign, so that I can pay the reduced amount online before the campaign deadline ends.
2. As a vehicle owner, I want to know which of my summonses are blocking my annual road tax renewal, so that I can prioritize settling the urgent ones first.
3. As a motorist who prefers using Bahasa Melayu, I want to ask questions in everyday conversational language, so that I do not have to travel and wait in long queues at a police station counter just to get basic help.
